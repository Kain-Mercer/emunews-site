# EmuNews

**Always watching the horizon.**

The web edition of EmuNews, a news aggregator that watches a set of RSS feeds, scores each story for relevance and tags it by topic.

**Read it here: https://kain-mercer.github.io/emunews-site/**

The site rebuilds itself every 30 minutes. The `gh-pages` branch holds the latest build only and is replaced on each update.

Headlines and summaries come from each outlet's public RSS feed, and every story links to the original on the publisher's site.
